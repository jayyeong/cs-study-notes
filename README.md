1. [네트워크 1 — 계층과 패킷 전달](study/network/01-layers-and-routing.md)을 읽고 그림을 보지 않고 설명합니다.
2. [네트워크 2 — TCP·UDP와 연결 관리](study/network/02-transport.md), [네트워크 3 — DNS·HTTP·TLS·상태 관리](study/network/03-web.md)를 학습합니다.
3. [전체 흐름과 장애 진단](study/network/04-end-to-end.md)으로 개념을 연결합니다.
4. [면접 질문 32개](interview/network.md)의 답을 가리고 소리 내어 답합니다.
5. [모의면접](interview/mock-interview.md)을 진행하고 [복습 기록](progress.md)에 실제 결과를 남깁니다.

## 학습 원칙

- 답변은 **정의 → 이유 → 동작 → 예시 → 한계**로 구성합니다.
- TCP의 기본 원리와 Reno 같은 특정 알고리즘의 동작을 구분합니다.
- HTTP·TLS·IP 버전을 명시합니다. “항상”, “무조건”이 들어간 문장은 예외를 확인합니다.
- 모르는 내용은 추측으로 단정하지 말고 확인할 질문으로 남깁니다.
- 이 저장소와 Notion 사이의 자동 동기화는 설정되어 있지 않습니다. 갱신 시점을 출처 문서에 기록합니다.
